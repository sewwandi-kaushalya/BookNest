# 📚 BookNest

> **Read. Discover. Repeat.**

BookNest is a modern and responsive online bookstore frontend built with **React.js** and **Tailwind CSS**. It provides a clean and user-friendly interface for discovering books, exploring categories, managing a wishlist, adding books to a cart, and completing a demo checkout process.

## 📸 Preview

### Home Page

BookNest features a modern hero section, curated books, categories, and a clean bookstore experience.

### Books

Browse the available collection with search, category filtering, and sorting options.

### Book Details

View individual book information, ratings, prices, descriptions, and availability.

### Cart & Checkout

Add books to the shopping cart, update quantities, and complete a frontend demo checkout.

## ✨ Features

- 🏠 Modern and responsive homepage
- 📚 Browse book collection
- 🔍 Search books by title or author
- 🏷️ Filter books by category
- ↕️ Sort books by price and rating
- 📖 Book details page
- ❤️ Wishlist functionality
- 🛒 Shopping cart
- ➕ Increase / decrease cart quantity
- 🗑️ Remove books from cart
- 💳 Demo checkout page
- 👤 Login page
- 📝 Registration page
- 📱 Fully responsive design
- 🧭 React Router navigation
- 🎨 Modern UI with Tailwind CSS
